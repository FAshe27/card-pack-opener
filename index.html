Pack slots

Odds are per pack. “Specific card” is the chance a pack contains one particular card of that rarity. Holo chance applies to each card pulled. Pulls use your browser's secure random number generator.

Card sets

Import a set from CSV

One row per card. Columns: name, rarity, subtitle, details, image (header row recommended; only name and rarity are required). Rarity can be common, uncommon, rare, epic, legendary, chase (or C/U/R/E/L/X). The details column is the free-text box at the bottom of the card: stats, fun facts, flavor text, anything.
