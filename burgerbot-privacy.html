Privacy Policy — BurgerBot Revival Tour

Last updated: October 19, 2026

What this is

BurgerBot Revival Tour is a small hobby project: an automated script that generates a random, fictional burger (an image plus a caption listing its ingredients) and posts it to the BurgerBot Revival Tour Facebook Page roughly every 30 minutes, using Meta's Graph API. It exists purely for fun.

What data we collect

None. The BurgerBot application does not collect, receive, store, or process any personal data about Facebook users or Page visitors.

  • There is no login, sign-up, or user account of any kind.
  • There are no cookies, analytics, trackers, or advertising tools.
  • The application never reads information about people who view, like, comment on, or share the Page's posts.
  • The only Meta permissions the application uses (pages_manage_posts, pages_read_engagement, and pages_show_list) are used by the Page's own administrator, through the administrator's own access token, solely to publish the Page's posts and to confirm which Page the token belongs to.

What Facebook collects

Your use of Facebook itself — including viewing the BurgerBot Revival Tour Page — is governed by Meta's own Privacy Policy, which describes what Meta collects and how it is used. That data is held by Meta, not by this project.

Data deletion

Because this application collects and stores no user data, there is no user data held by BurgerBot Revival Tour to delete. If you believe the application has nevertheless received or stored any information about you, message the BurgerBot Revival Tour Facebook Page and describe your request — anything found will be deleted and you will be told once it is done.

Changes to this policy

If this policy ever changes, the updated version will be posted at this same address with a new "last updated" date.

Contact

Questions about this policy: send a message to the BurgerBot Revival Tour Page on Facebook.
